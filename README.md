# Dr. Diego Montes Chiropractic

![Dr. Diego Montes Chiropractic Office](https://pub-af6f4cefa51449e1bc1879efb21cc1a0.r2.dev/5.Chiropractic-office.png)

## Overview

Professional chiropractic website for Dr. Diego Montes, D.C., providing expert spinal health care and holistic wellness solutions. This modern, responsive website showcases services, patient success stories, and educational resources for optimal health.

## Features

- **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- **Video Integration** - Engaging video content showcasing patient testimonials and clinic environment
- **Service Pages** - Detailed information about chiropractic treatments and wellness programs
- **Patient Success Stories** - Real testimonials from satisfied patients
- **FAQ Section** - Comprehensive answers to common questions
- **Contact Forms** - Easy appointment booking and inquiries
- **Team Information** - Meet the healthcare professionals
- **News & Updates** - Latest articles and health tips

## Technology Stack

- HTML5
- CSS3 (SCSS)
- JavaScript
- Bootstrap 5
- Swiper.js for carousels
- Animate.css for animations
- Live Server for development

## Pages

- **Home** - Hero section with engaging video background
- **About** - Clinic story and mission
- **Services** - Comprehensive treatment options
- **Team** - Healthcare professionals
- **Patient Success Stories** - Testimonials
- **Pricing** - Transparent pricing information
- **FAQ** - Frequently asked questions
- **News** - Health articles and updates
- **Contact** - Get in touch and book appointments

## Installation

```bash
# Clone the repository
git clone https://github.com/StynerStiner/DrDiegoMontes.git

# Navigate to project directory
cd DrDiegoMontes

# Install dependencies
npm install

# Start development server
npm start
```

## Development

```bash
# Run live server
npm start

# Server will start at http://localhost:8080
```
